# 📝 Список задач (To-Do List)

Простое и стильное веб-приложение для ведения списка дел, оформленное в виде классического линованного блокнота с полями.

## ✨ Особенности
* **Дизайн бумажного блокнота:** теплый оттенок бумаги, горизонтальные линии строк, вертикальная красная линия полей и яркая оранжевая рамка.
* **Сохранение данных:** все добавленные задачи автоматически сохраняются в `localStorage` браузера — список не пропадет после перезагрузки страницы.
* **Управление списком:** быстрое добавление новых пунктов, защита от пустого ввода и удобное удаление выполненных задач в один клик.

## 🛠 Технологии
* **HTML5** — структура страницы.
* **CSS3** — Flexbox-верстка, кастомная стилизация под блокнот, анимации наведения и нажатия.
* **JavaScript (ES6+)** — работа с DOM и локальным хранилищем (`localStorage`).

## 🚀 Как запустить проект
1. Склонируйте репозиторий на свой компьютер:
   ```bash
   git clone https://github.com
   ```
2. Откройте файл `index.html` в любом современном браузере.

## 📂 Структура проекта
* `index.html` — основная разметка приложения.
* `style.css` — стилизация и оформление интерфейса.
* `script.js` — логика добавления, удаления и сохранения задач.
